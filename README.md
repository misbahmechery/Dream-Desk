# Dream Desk

An open-source furniture design of my personal dream desk, designed in Blender and brought to life by a skilled carpenter.

This project documents the design, dimensions, materials, construction details, and build process so that others can understand, reproduce, modify, and improve the desk.

## About the Project

The Dream Desk started as a personal design project. I designed the desk in Blender based on how I wanted my ideal workspace to look and function.

After completing the design, I worked with a carpenter who transformed the digital design into a real piece of furniture using his craftsmanship and woodworking skills.

This repository is my attempt to make the complete design publicly available so that anyone interested can explore it, build their own version, or create something new from it.

## What's Included

* Blender source files
* Dimensions and technical drawings
* Build guide
* Material and wood specifications
* Construction and assembly details
* Photos from the build process
* Photos of the finished desk

## Design

The original design was created in **Blender**. ( But I recommend using a cad software for accurate measurement )

The Blender files are provided as the primary source files fo r the project. You can open, inspect, modify, and create your own version of the desk.

## Build Guide

A detailed PDF build guide will document the process from the original design to the finished desk.

It will include:

* Overall dimensions
* Individual component measurements
* Materials
* Wood specifications
* Cutting information
* Assembly instructions
* Finishing details
* Notes from the actual build

## Version

**Current version:** v1.0

This is the first physical version of the Dream Desk. Future improvements or modifications may be added as new versions.

## Why Open Source?

I wanted to share the design instead of keeping it as a personal project.

If this design is useful to you, feel free to study it, modify it, build your own version, and improve upon it.

If you build one, I'd love to see what you create.
